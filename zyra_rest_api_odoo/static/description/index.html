Zyra Rest API Manager

Build secure REST APIs from Odoo with API keys, authentication endpoints, model-based dynamic CRUD APIs, custom APIs, and built-in rate limiting.

Key Features
  • Create and manage API application keys from Odoo backend.
  • Control built-in authentication endpoints from UI (activate/deactivate).
  • Create model endpoints with selected fields and related model data.
  • Configure custom endpoints for JSON or text responses.
  • Apply endpoint-level rate limits and authentication rules.
  • Use API key or authenticated session to access protected APIs.
Auth APIs

Built-in authentication endpoints (all manageable from Odoo UI):

  • POST /api/login: Login with login and password, returns uid and session_id.
  • POST /api/register: Public user registration with name, email, password (optional phone).
  • POST /api/password/reset: Trigger reset flow using email.
  • GET/POST /api/user/details: Get logged-in user profile, groups, model access, and record rules (requires session).

Security controls: failed-attempt window and cooldown support on login/reset endpoints.

Model API (Full CRUD)

Dynamic model endpoint pattern: /api/model/<model_name> and /api/model/<model_name>/<record_id>

  • GET: list records with pagination (limit, offset, order, optional domain).
  • GET by ID: read a single record including configured related data.
  • POST: create new record from JSON payload.
  • PUT/PATCH: update existing record by ID.
  • DELETE: delete record by ID.

You can choose allowed fields per model, set endpoint domain filters, and secure each endpoint using API key/session and rate limits.

Custom API Endpoints
  • Route format: /api/custom/<route_key>.
  • Fast custom responses with JSON or plain text response type.
  • Per-endpoint API key/session requirement and per-minute rate limit support.
  • Ideal for lightweight integration callbacks, configs, and public metadata endpoints.
