Zyra Rest API Manager

Manage REST endpoints in Odoo with API key security, authentication endpoints, and configurable rate limits.

Key Features
  • Create and manage API application keys from Odoo.
  • Enable/disable built-in authentication endpoints from the UI.
  • Expose model-based endpoints for structured CRUD API access.
  • Create custom endpoints for tailored business integrations.
  • Apply rate limiting rules to protect your APIs.
  • Control endpoint access and API relations from dedicated menus.
Included APIs
  • Authentication API endpoints (login/register flow support).
  • Model endpoint management for standard data operations.
  • Custom endpoint management for project-specific API contracts.
How It Works
  1. Install the module and open the Zyra REST API menus.
  2. Create API app keys and configure authentication endpoint behavior.
  3. Define model or custom endpoints based on your integration needs.
  4. Set rate limits and relations, then test your endpoints externally.
